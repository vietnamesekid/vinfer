# reference/

Clone third-party engines here **for reading only**. Everything in this folder except this
README is git-ignored.

```bash
git clone --depth 1 https://github.com/vllm-project/vllm reference/vllm
git clone --depth 1 https://github.com/sgl-project/sglang reference/sglang
```

If you adapt code from here, keep the original license header and add a source link in the file
where it ends up in `src/`.

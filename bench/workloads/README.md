# Workloads

Fixed and seeded. Never edit a workload in place: add a new version (`W1-v2`) instead.

| ID | Shape | Represents | Main metrics |
|----|-------|------------|--------------|
| W1 | Short prompt, short output | Chat | TTFT, TPOT |
| W2 | Long prompt, short output | RAG, document reading | TTFT, peak VRAM |
| W3 | Short prompt, long output | Code generation | TPOT, throughput |
| W4 | Multi-turn, shared prefix | Agent loop | Prefix cache hit rate, TTFT |

Each workload runs a closed-loop concurrency sweep (**1, 8, 32, 128**) and, for goodput, a
Poisson arrival-rate sweep (docs/benchmarking.md).

## Version 1 (generated by `generate.py`, spec in `SPECS`)

| ID | Source (pinned revision in `manifest.json`) | Requests | Prompt tokens p50 / max | Output tokens |
|----|------|----------|------------------|---------------|
| W1-v1 | ShareGPT V3, first user turn | 1000 | 37 / 1013 | recorded reply, clipped 4–512 (p50 253) |
| W2-v1 | LongBench-v2 context cut to 4k/8k/16k/32k + question | 200 | 8.6k / 33k | uniform 64–256 |
| W3-v1 | HumanEval + MBPP (sanitized test) | 400 | 51 / 441 | uniform 1024–2048 |
| W4-v1 | Shared agent system prompt (~3.3k tokens) + ShareGPT, 3–6 turns | 804 (200 sessions) | 3.8k / 5.4k | recorded reply, clipped 16–512 |

Tokens are counted with the Qwen3.5-2B tokenizer and chat template. `requests.jsonl` is
git-ignored (W2/W4 are 11–13 MB, and ShareGPT content is not redistributed); `manifest.json`
is committed and `make workloads CHECK=1` proves a regenerated file is byte-identical.
W4 turns of one session are sent in order: turn k+1 only after turn k finished.
